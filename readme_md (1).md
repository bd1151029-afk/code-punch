# 高美惠 - 大學生個人作品與簡介網站 (Personal Portfolio)

這是一個為 **黎明技術學院 數位多媒體系 高美惠** 所設計的單一檔案（Single-File）個人介紹網站。網站採用溫暖優雅的淺色調配色風格，完美呈現個人簡歷、技能特色（小說創作與數位多媒體）以及社群聯繫方式。

---

## 🌟 網站特色與亮點

1. **響應式網頁設計 (RWD)：** 支援手機、平板與桌上型電腦，瀏覽體驗順暢。
2. **現代淺色溫暖風格：** 使用暖奶茶色與玫瑰金/赤陶色系（Warm Terracotta），展現氣質與專業感。
3. **優雅中英字體搭配：** 採用 Google Fonts 的「思源宋體 (Noto Serif TC)」呈現主標題與文學質感，「思源黑體 (Noto Sans TC)」確保內容易讀性。
4. **互動式小說試閱彈窗 (Modal)：** 點擊專長中的小說創作，可跳出彈窗閱覽寫作範例片段。
5. **一鍵複製聯繫資訊：** 點擊 Email 或 Line ID 自動複製至剪貼簿，並顯示彈出式提示（Toast Notification）。

## 🚀 如何使用與部署

### 1. 本地預覽
直接在瀏覽器中雙擊打開 `index.html` 檔案即可預覽。

### 2. 免費部署上線 (如 GitHub Pages)
1. 在 GitHub 上建立一個新的公開儲存庫 (Public Repository)。
2. 將 `index.html` 與 `README.md` 上傳至 GitHub 儲存庫。
3. 前往儲存庫的 **Settings > Pages**。
4. 在 **Source** 選擇 `main` 分支並儲存，幾分鐘後即可獲得專屬的個人網站網址。
